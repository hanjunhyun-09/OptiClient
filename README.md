# OptiClient — 마인크래프트 최적화 클라이언트

**런처(C# WPF)** + **HUD 모드(26.3 / 1.21.11 / 1.21.1 / 1.20.1 Fabric, 1.8.9 Forge)** 로 이루어진 최적화 클라이언트입니다.

- 런처: 버전별 프로필을 만들고, 로더(Fabric/Forge)와 최적화 모드를 자동 설치하고, 모드를 켜고 끄거나 Modrinth에서 검색해 추가합니다.
- HUD 모드: FPS, 좌표, CPS, 키 입력, 갑옷 내구도, 포션 효과 등을 화면에 띄우고 드래그로 위치를 바꿉니다.
- PvP 기능: 리치 · 콤보 · 타깃 HUD · 아이템 개수 · 퍼스펙티브(자유 시점) · 커스텀 크로스헤어 · 웅크리기 토글 · 흔들림 끄기 · 낮은 불 · 히트박스.
- **공식 런처 없이 바로 실행**합니다 (게임 파일·Java 를 직접 받아 실행).
- **정품 계정**은 공식 런처에 로그인을 맡기고, 공식 런처의 플레이 버튼까지 **자동으로 눌러** 줍니다 (플레이 한 번이면 끝).

## 다운로드 (친구에게 나눠 줄 때)

1. [최신 릴리스](https://github.com/hanjunhyun-09/OptiClient/releases/latest) 에서 **OptiClient.zip** 을 받아 압축을 풉니다.
2. `OptiClientLauncher.exe` 실행 (`hud` 폴더는 exe 옆에 그대로 두기).
   서명되지 않은 exe 라 처음에 Windows 경고가 뜨면 **추가 정보 → 실행** 을 누릅니다.
3. 이후 새 버전이 나오면 런처를 켤 때 **업데이트할지 물어봅니다** (설정 탭의 **업데이트 확인** 으로도 확인).

## 새 버전 배포 (만드는 사람)

```powershell
powershell -ExecutionPolicy Bypass -File .\release.ps1 1.0.1 "바뀐 점 설명"
```

버전 올리기 → 전체 빌드 → git 커밋·태그·푸시 → GitHub 릴리스(`OptiClient.zip`) 업로드까지 한 번에 합니다.
런처는 GitHub 최신 릴리스 태그와 자기 버전을 비교해서, 새 버전이면 zip 을 받아(해시 확인) 런처 exe 와 `hud` 폴더를 바꾸고 다시 켜집니다.
(프로젝트 폴더 안에서 실행한 개발 빌드는 업데이트하지 않습니다.)

## 빠른 시작 (직접 빌드)

```powershell
powershell -ExecutionPolicy Bypass -File .\build-all.ps1
.\dist\OptiClient\OptiClientLauncher.exe
```

1. 왼쪽 위 **계정** 을 눌러 **정품 (추천)** 또는 오프라인 닉네임을 선택
2. 프로필 선택 (기본: `최신 버전 26.3`, `1.21 최신 1.21.11`, `야생 1.21.1`, `모드팩 1.20.1`, `PvP 1.8.9`)
3. **플레이 ▶** → 설치 후 바로 실행 (처음에는 게임 파일·리소스·Java 를 받느라 몇 분 걸림)
4. 게임 안에서 **Right Shift** 로 메뉴 (1.8.9 는 PolyPatcher·OneConfig 와 겹치지 않게 **오른쪽 Ctrl**)

> 런처 실행에는 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) 이 필요합니다.

## 계정

| 방식 | 설명 |
|---|---|
| **정품 (추천)** | 공식 마인크래프트 런처에 로그인된 계정으로 실행. 하이픽셀 같은 정품 서버·Realms 접속 가능. 앱 ID 필요 없음 |
| 오프라인 | 닉네임만 넣으면 바로 실행. 싱글플레이·LAN·오프라인 서버 전용 (정품 서버 접속 불가) |
| Microsoft (앱 ID) | 공식 런처 없이 정품 실행. Mojang 정책상 **직접 등록·승인받은 앱 ID** 가 있어야 함 (아래) |

### 정품 (공식 런처 자동 플레이)

[플레이 ▶] 를 한 번 누르면:
1. 모드·로더를 설치하고 공식 런처에 `OptiClient · 프로필 이름` 설치 구성을 등록 (가장 최근 사용으로 표시해 자동 선택)
2. 공식 런처가 켜져 있으면 한 번 닫았다가 (설치 구성 반영) 다시 염
3. 공식 런처 창에서 초록색 **플레이** 버튼을 찾아 대신 눌러 줌 → 게임 실행
4. (기본) 게임 창이 뜨고 5초 뒤 공식 런처를 닫음. 게임은 그대로 실행됨. 런처 **설정** 탭의 "게임이 켜지면 공식 런처 닫기" 로 끌 수 있음

- 처음 한 번은 공식 런처에서 Microsoft 계정으로 로그인해 두세요.
- OptiClient 는 계정 정보·토큰·비밀번호를 읽지도, 저장하지도 않습니다. 로그인은 전부 공식 런처가 처리합니다.
- 클릭은 창에 메시지로 보내기 때문에 실제 마우스 커서는 움직이지 않습니다.
- 공식 런처가 자바 에디션 화면이 아닌 곳(홈, 베드락 등)에서 열리면 버튼을 못 찾을 수 있어요. 그때는 런처 로그에 안내가 뜨니 플레이를 직접 눌러 주세요. 한 번 자바 에디션 화면에서 실행하면 다음부터는 그 화면으로 열립니다.
- 메인 화면의 **정품으로 플레이 (공식 런처)** 버튼은 계정 설정과 상관없이 이 방식으로 실행합니다.

### Microsoft (앱 ID) 로그인 준비 (한 번만)
1. [Azure 앱 등록](https://portal.azure.com/#view/Microsoft_AAD_RegisteredApps/ApplicationsListBlade) → 새 등록 → 지원 계정 유형 "개인 Microsoft 계정"
2. 인증 → "공용 클라이언트 흐름 허용" 을 예로
3. [Minecraft API 승인 신청](https://aka.ms/mce-reviewappid) (며칠 걸릴 수 있음)
4. 승인되면 런처 계정 창의 "앱 클라이언트 ID" 에 넣고 로그인 (브라우저에 코드 입력)

로그인 정보(새로고침 토큰)는 Windows DPAPI 로 암호화해 `%APPDATA%\.opticlient\accounts.json` 에 저장합니다. 게임 토큰은 저장하지 않습니다.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `common/` | 버전 공통 HUD 코드 (Java 8 문법, Gson만 사용). 모든 모드가 소스를 공유 |
| `common-mojmap/` | Mojang 이름을 쓰는 1.21.11·26.x 공통 코드 (게임 정보, mixin) |
| `mod-fabric-26.3/` | Fabric 26.3 모드 (Java 25, Loom 1.19, 난독화 없음) |
| `mod-fabric-1.21.11/` | Fabric 1.21.11 모드 (Java 21, Loom 1.19 + Mojang 매핑) |
| `mod-fabric-1.21.1/` | Fabric 1.21.1 모드 (Java 21, Loom 1.11) |
| `mod-fabric-1.20.1/` | Fabric 1.20.1 모드 (Java 17) |
| `mod-forge-1.8.9/` | Forge 1.8.9 모드 (Java 8, essential-loom) |
| `launcher/OptiClientLauncher/` | WPF 런처 (.NET 10) |
| `build-all.ps1` | 전체 빌드 → `dist/OptiClient/` (exe + `hud/*.jar`) |

HUD 모듈을 추가하려면 `common/.../Modules.java` 에 클래스를 하나 만들고 `createAll()` 에 넣으면 세 버전 모두에 적용됩니다.
버전마다 다른 부분은 `HudRenderer`(그리기)와 `GameInfo`(게임 상태) 구현뿐입니다.

## 런처

- 떠다니는 빛과 입자가 있는 움직이는 배경, 직접 만든 제목 표시줄
- 왼쪽 프로필 목록: 버전마다 다른 색 배지, 마우스를 올리면 살짝 밀림
- 히어로: 프로필 이름·버전·모드 수, 버전 색으로 물드는 배경, 빛이 맥박처럼 퍼지는 **플레이** 버튼
- 탭: 모드(토글 스위치) / 설정(버전 알약 버튼·메모리 슬라이더·창 크기) / 로그
- Modrinth 검색: 모드 아이콘·이름·만든 사람·설명·다운로드 수, 카테고리 칩, `＋ 담기` 로 여러 개 골라 **한꺼번에 추가**
- 창이 열릴 때·프로필을 바꿀 때 미끄러지며 나타나는 애니메이션, 오른쪽 아래 알림
- **다른 런처에서 가져오기**: 다른 런처·클라이언트의 설정과 모드팩을 프로필로 가져오기 (아래 참고)

## 다른 런처에서 가져오기

왼쪽 프로필 목록 아래 **⇩ 다른 런처에서 가져오기** 를 누르면 PC 에 있는 런처를 찾아 보여 줍니다.

### PvP 클라이언트 프로필 그대로 가져오기

| 클라이언트 | 읽는 파일 | 가져오는 것 |
|---|---|---|
| Lunar Client | `~\.lunarclient\settings\game\<프로필>\mods.json` | HUD 켜짐 · 위치(기준 위치 포함) · 크기, 줌 · 퍼스펙티브 · 토글 웅크리기/달리기 · 히트박스 · 크로스헤어 · 흔들림, 게임 설정(`optionsLC.txt`) |
| Feather Client | `.minecraft\feather\configuration\profiles\<프로필>.json` | HUD 켜짐 · 위치 · 크기, 줌 · 퍼스펙티브 · 토글 달리기 · 히트박스 · 크로스헤어 · 밝기, 게임 설정(`mc_options_v2.txt`) |
| Badlion Client | `.minecraft\BLClient-Mod-Profiles\<프로필>.zip` | HUD 켜짐, 줌 · 퍼스펙티브 · 토글 달리기 · 히트박스 · 크로스헤어 · 밝기 (Badlion 은 위치를 프로필에 저장하지 않아 위치는 OptiClient 기본 배치) |
| Silent Client | `.minecraft\silent\configs\<설정>.json` | HUD 켜짐 · 위치, 줌 · 퍼스펙티브 · 토글 달리기 · 히트박스 · 크로스헤어 · 밝기 |

- 클라이언트마다 프로필이 여러 개면 모두 보여 주고, **지금 쓰는 프로필을 맨 위**에 `(사용 중)` 으로 표시합니다.
- 옮기는 HUD: FPS · CPS · 핑 · 좌표 · 시계 · 포션 · 갑옷 · 키 입력 · 리치 · 콤보 · 아이템 개수 · 나침반 · 허기/포화 · 메모리 · 서버 주소 · 속도 · 토글 상태.
  OptiClient 에 없는 모드(미니맵 · 웨이포인트 · 커스텀 크로스헤어 그림 등)는 건너뜁니다.
- 위치는 그 클라이언트의 **기준 위치(왼쪽 위 · 오른쪽 아래 · 가운데 아래 …)를 그대로** 써서, 창 크기가 달라도 같은 자리에 붙습니다.
  게임 안 편집 화면(Right Shift)에서 옮기면 그때부터는 OptiClient 방식 좌표로 바뀝니다.
- 계정 파일(`accounts.json`, `account.txt`, `accounts.dat` 등)은 열지 않습니다.

### 런처 · 모드팩

| 찾는 곳 | 가져오는 것 |
|---|---|
| 공식 런처 (`.minecraft`) | 게임 설정, 서버 목록, 리소스팩, 셰이더, (버전이 맞으면) 모드 |
| Prism / PolyMC 인스턴스 | 게임 설정, 서버, 리소스팩, 셰이더, 모드, 모드 설정, 월드 |
| Modrinth App 프로필 | 〃 |
| CurseForge 인스턴스 | 〃 |
| `.mrpack` 모드팩 파일 | 모드팩에 든 모드(Modrinth 에서 받음, 해시 확인) · 설정 파일 |

- **새 프로필 만들기** 또는 **선택한 프로필에 넣기** 중에서 고릅니다.
- 게임 설정은 키 배치·감도·시야각·소리·언어 등을 가져오고, **그래픽 설정은 기본으로 OptiClient 최적화 값을 유지**합니다 (켜면 그래픽도 가져옴).
- 1.8.9 ↔ 1.13 이후 버전 사이에서는 **키 배치를 자동으로 바꿔서** 넣습니다 (1.8.9 키 번호 ↔ `key.keyboard.w` 형식).
- 모드는 **OptiClient 가 실행할 수 있는 버전·로더와 같을 때만** 가져옵니다 (26.3 / 1.21.11 / 1.21.1 / 1.20.1 Fabric, 1.8.9 Forge).
  Forge·NeoForge·Quilt 나 다른 버전 모드팩은 설정·서버·리소스팩·셰이더만 가져옵니다.
- 모드 파일은 Modrinth 에 해시로 물어봐서 찾으면 Modrinth 모드로, 못 찾으면 로컬 파일로 넣습니다.
  Sodium 처럼 OptiClient 최적화 모드와 겹치는 모드는 두 개가 되지 않게 건너뜁니다.
- 원래 서버 목록은 `servers.dat.opticlient-backup` 으로 보관하고, 리소스팩·셰이더·월드는 같은 이름이 있으면 건너뜁니다.
- 계정·로그인 파일(각 런처의 accounts 파일 등)은 **읽지 않습니다**. 게임 폴더의 설정·모드 파일만 봅니다.
- CurseForge 모드팩 zip 은 CurseForge API 키가 있어야 받을 수 있어서, CurseForge 앱에서 설치한 뒤 인스턴스로 가져오세요.

## 로고

16×16 도트 엠블럼(빨간 배지 + 흰 고리 + 번개). 런처 exe·창 아이콘·제목 표시줄, 게임 안 모드 메뉴·타이틀 화면, 모드 목록 아이콘에 같은 그림을 씁니다. 원본: `launcher/OptiClientLauncher/Assets/`.

## 타이틀 화면

기본 타이틀 화면 대신 OptiClient 타이틀 화면이 열립니다 (메뉴 → 설정에서 끌 수 있음).
그라데이션 배경 · 떠오르는 입자 · 숨쉬는 빛 · 도트 로고 "OPTICLIENT" · 하나씩 올라오는 버튼(싱글플레이/멀티플레이/설정/종료).
아래쪽 "기본 타이틀 화면" 을 누르면 원래 화면으로 갈 수 있습니다.

## 게임 안 메뉴 (Right Shift)

빨간색 기본 테마의 카드형 메뉴입니다.

| 탭 | 내용 |
|---|---|
| 모드 메뉴 | 카드 격자. 카테고리(전체/HUD/PvP/성능/편의), 검색, 즐겨찾기(하트) 필터, 카드마다 켜짐/꺼짐·톱니(개별 설정)·하트 버튼. 마우스 휠로 스크롤 |
| HUD 편집 | 드래그로 옮기기 · 클릭하면 크기 도구 막대(－ / 100% / ＋ / 삭제) · 마우스 휠로 크기(50~200%) · 모서리 × 나 오른쪽 클릭으로 바로 삭제 · 초기화 · 완료 · **정렬 안내선**: 다른 HUD 의 왼쪽·가운데·오른쪽(위·가운데·아래)이나 화면 가운데와 같은 줄에 오면 선이 보이고, 4칸 안으로 가까이 가면 그 줄에 붙음 |
| 설정 | HUD 스타일, 강조색, 배경, 그림자, 크로스헤어 모양·색·크기, 퍼스펙티브 키 방식(누르는 동안/토글), 줌 배율, 부스트 렌더 거리, 위치 초기화 |

**개별 설정 (카드의 톱니)**: 모드마다 따로 정합니다.

- HUD: 켜기, 크기, 배경(전체 설정 따름/켬/끔), 글자 그림자, 글자색(흰색·강조색·초록·노랑·하늘·분홍·회색), 이름 표시(예: `FPS`), HUD 편집에서 위치 옮기기, 이 HUD 위치 초기화
- HUD 별 옵션: 포션 10초 안에 끝나는 효과 빨갛게 · CPS 오른쪽 클릭 표시 · 좌표 방향/바이옴 표시 · 시계 초/오전오후 · 갑옷 손에 든 아이템 · 키 입력 마우스/스페이스 · 인벤토리 핫바 줄/빈 칸 테두리
- 기능: FPS 부스트 렌더 거리 · 줌 배율 · 크로스헤어 모양/색/크기 · 퍼스펙티브 키 방식

ESC: 검색 중이면 검색 끝내기 → 개별 설정 창이 열려 있으면 닫기 → HUD 편집 중이면 메뉴로 → 그 외에는 닫기.

## HUD 스타일

| 스타일 | 모양 |
|---|---|
| 모던 (기본) | 둥근 어두운 유리 배경, 왼쪽 위 짧은 강조선, 라벨은 강조색·값은 흰색, 갑옷 내구도 막대 |

| 미니멀 | 배경 없이 글자만 |

강조색: 빨강(기본) · 주황 · 핑크 · 보라 · 하늘 · 민트 · 무지개.
왼쪽 HUD 요소는 켜진 것끼리 빈칸 없이 자동으로 쌓이고, 직접 옮기면 그 자리에 고정됩니다.

## 기본 FPS 최적화 (항상)

게임을 켤 때마다 FPS 제한을 무제한으로 풀고 수직동기화를 끕니다 (1.21.11/26.3 은 가만히 있을 때 FPS 를 낮추는 기능도 끔).
마인크래프트 기본값(최대 120 FPS)에 묶이지 않게 하는 설정이며, 메뉴 → 설정 → "FPS 제한 해제 (항상)" 으로 끌 수 있습니다.

## PvP FPS 부스트

메뉴의 **FPS 부스트** 카드를 켜면 그래픽 설정을 FPS 위주로 바꾸고, 끄면 원래 값으로 되돌립니다.

빠른 그래픽 · 렌더 거리 제한(기본 6청크, 설정에서 변경) · 시뮬레이션 거리 5 · 파티클 최소 · 구름 끔 · 그림자 끔 ·
부드러운 조명 끔 · 바이옴 혼합 0 · 수직동기화 끔 · FPS 제한 해제 · 엔티티 표시 거리 50% · 인챈트 반짝임 끔 (1.21.11/26.3 은 잎 투명 끔, 청크 페이드 끔, 가만히 있을 때 FPS 제한 해제 추가)

> FPS 는 그래픽카드·CPU 에 따라 정해지므로 특정 숫자를 보장할 수는 없습니다. 같은 PC 에서 최대한 끌어올리는 기능입니다.

### 측정 예시 (런처로 실제 설치 + 직접 실행, 1920×1080 창, 같은 시드 월드, 시야각 97 등 사용자 설정, HUD 기본값 켬)

PvP 장면: 마법부여 갑옷 좀비 12마리 + 파티클. 복잡한 장면: 여기에 이름표 단 좀비 40마리가 돌아다니고 화면을 계속 돌림 (사람 많은 서버 흉내).
2026-11-15 측정, Medal 녹화가 켜진 상태 (평균 FPS).

| 버전 | PvP 부스트 끔 | PvP 부스트 켬 | 복잡한 장면 부스트 끔 | 복잡한 장면 부스트 켬 |
|---|---|---|---|---|
| 26.3 | 666 | 906 | 678 | 771 |
| 1.21.1 | 812 | 1,052 | 683 | 931 |
| 1.20.1 | 792 | 925 | 747 | 774 |
| 1.8.9 | 504 | 772 | 393 | 642 |

1.8.9 는 마인크래프트 자체 그리기가 느려서 **PvP 부스트를 켜야** 목표(PvP 600 이상, 사람 많은 장면 500 이상)를 넘습니다. 그래서 1.8.9 는 **PvP 부스트가 처음부터 켜져** 있습니다 (메뉴에서 끄면 끈 채로 유지).
1.8.9 에서는 함께 설치되는 PolyPatcher 의 **HUD 캐싱**(HUD 를 1초에 60번만 다시 그리고, 키·마우스를 누르면 바로 다시 그림)을 항상 켜고,
반짝임 끄기·PvP 부스트 중에는 PolyPatcher 의 **반짝임 끄기**를 켭니다. (1.8.9 사람 많은 장면 부스트 켬: 445 → 642)

가장 큰 개선은 **HUD 묶어 그리기**였습니다. 1.20.1·1.21.1 은 사각형·글자를 하나 그릴 때마다 GPU 에 그리기 명령을 따로 보내서
HUD 만으로 FPS 가 절반(약 1,100 → 550)으로 떨어졌는데, 한 번에 묶어 그리도록 바꿔 약 1,000 으로 돌아왔습니다.
월드·장면마다 달라지는 값이라 버전끼리 정확히 비교할 수는 없습니다.

## 런처가 설치하는 최적화 모드

**26.3 / 1.21.11 / 1.21.1 / 1.20.1 (Fabric)**: Fabric API, Sodium, Lithium, FerriteCore, ImmediatelyFast, Entity Culling, ModernFix, Dynamic FPS, Krypton,
MoreCulling, BadOptimizations, **Exordium**(HUD·UI 를 낮은 주기로 그림), **Ixeris**(창·입력 처리 별도 스레드)
(ModernFix 는 1.21.11·26.3, Exordium 은 26.3 용이 없어서 그 버전에서는 빠짐. 1.20.1 은 MoreCulling 에 필요한 Cloth Config 를 함께 설치)

> Exordium·Ixeris 는 PC 에 설치된 다른 런처들의 PvP 모드팩 구성을 참고해 넣었고, 같은 시드 월드의 PvP 장면에서
> 넣기 전/후를 재서 FPS 가 오른 것을 확인했습니다. (1.8.9 를 최신 Java 8 로 돌리는 방법도 시험했지만 오히려 느려서 넣지 않았습니다.)

**1.8.9 (Forge)**: PolyPatcher, Entity Culling — OptiFine 은 자동 다운로드가 불가능해서 [optifine.net](https://optifine.net) 에서 받아 **파일 추가**로 넣어야 합니다.

추가로:
- 필요한 의존성 모드를 자동으로 찾아 함께 설치
- 프로필마다 게임 폴더가 따로 있어 (`%APPDATA%\.opticlient\profiles\<id>`) 월드·설정·모드가 섞이지 않음
- 첫 설치 시 FPS 위주 `options.txt` (렌더 거리 8, 빠른 그래픽, 파티클 최소, 구름·그림자 끔, 수직동기화 끔, FPS 제한 해제 등) + 한국어
- JVM 인수: 메모리 슬라이더 + G1GC 튜닝

|---|---|

## 게임 안 자동 테스트 (개발용)

각 모드 폴더에서 아래를 실행하면 개발용 마인크래프트가 열려 크리에이티브 월드를 만들고, 갑옷·효과를 준 뒤
HUD / 설정 화면 / 밤 / 밝기 최대 스크린샷을 `run-autotest/screenshots/` 에 저장하고 스스로 종료합니다.

```powershell
cd mod-fabric-1.21.1; .\gradlew runAutotest      # 26.3 / 1.21.11 / 1.20.1 도 동일
cd mod-forge-1.8.9;   .\gradlew autotestClient   # 1.8.9 는 별도 작업 이름
```

테스트 코드(`DevAutoTest`)는 `-Dopticlient.autotest=true` 일 때만 동작하고, 배포 jar 에서는 빠집니다.

## 알려진 한계

- 하이픽셀 등 일부 서버는 퍼스펙티브(자유 시점)를 허용하지 않습니다. 서버 규칙을 확인하고 쓰세요.

- Microsoft (앱 ID) 로그인은 Mojang 승인을 받은 앱 ID 가 있어야 동작합니다. 승인이 없으면 **정품 (공식 런처)** 방식을 쓰세요.
- 정품 자동 플레이는 공식 런처 화면의 버튼 색으로 위치를 찾습니다. 공식 런처 디자인이 크게 바뀌면 자동 클릭이 안 될 수 있고, 그때는 플레이를 직접 누르면 됩니다.
- 공식 런처의 "달리기: 전환" 옵션을 켜 둔 상태에서 V 토글을 함께 쓰면 달리기가 깜빡일 수 있습니다. 둘 중 하나만 쓰세요.
- 각 HUD 모드는 해당 버전 전용입니다 (1.21.1 모드는 1.21~1.21.1, 1.21.11 모드는 1.21.11, 26.3 모드는 26.3). 다른 버전은 렌더링 API가 달라 별도 모듈이 필요합니다.
- 26.3 / 1.21.11 모드를 빌드하려면 Gradle 이 Java 25 로 돌아야 합니다. `gradle/gradle-daemon-jvm.properties` 덕분에 처음 빌드할 때 자동으로 내려받습니다.
