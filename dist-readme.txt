OptiClient - 마인크래프트 최적화 클라이언트

[실행]
  OptiClientLauncher.exe 를 실행하세요.
  .NET 10 데스크톱 런타임이 없으면 처음 실행할 때 설치 안내가 나옵니다.
  hud 폴더는 exe 와 같은 곳에 그대로 두세요 (게임 안 HUD 모드가 들어 있습니다).

[지원 버전]
  26.3 / 1.21.11 / 1.21.1 / 1.20.1 (Fabric), 1.8.9 (Forge)

[처음 쓰는 순서]
  1. 위쪽 계정 칸을 눌러 계정을 정합니다 (정품이면 "정품 (추천)" - 공식 런처로 실행).
  2. 왼쪽에서 프로필(버전)을 고릅니다.
  3. 플레이를 누르면 필요한 파일과 최적화 모드를 받아 설치하고 실행합니다.

[다른 런처에서 가져오기]
  왼쪽 아래 "다른 런처에서 가져오기" 를 누르면
  Lunar / Feather / Badlion / Silent 클라이언트 프로필(HUD 배치, 모드 설정)과
  공식 런처 / Prism / Modrinth App / CurseForge 의 설정·모드팩을 가져올 수 있습니다.
  계정·로그인 정보는 읽지 않습니다.

[게임 안 키]
  오른쪽 Ctrl = OptiClient 메뉴 (1.8.9), Right Shift = 메뉴 (그 외 버전)
  C = 줌, V = 달리기 토글, G = 웅크리기 토글, 왼쪽 Alt = 퍼스펙티브

[데이터 위치]
  %APPDATA%\.opticlient  (프로필, 프로필별 게임 폴더)
